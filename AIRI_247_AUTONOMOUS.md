## 🧠 How It Works

### **Autonomous Loop** (Every 10 seconds)

```
1. Scan codebase for issues
   ├─ Compilation errors
   ├─ Test failures
   ├─ TODO comments
   └─ Code smells

2. Generate self-tasks
   ├─ Priority > 70: Act immediately
   ├─ Priority 50-70: Queue for later
   └─ Priority < 50: Monitor

3. Execute high-priority tasks
   ├─ Debug errors
   ├─ Implement features
   ├─ Refactor code
   └─ Write tests

4. Report progress
   └─ Notify user of completed work
```

### **Learning System**

```
Complete Task → Learn Pattern → Increase Competence
     ↓
Fail Task → Analyze Failure → Adjust Strategy
     ↓
Background Learning → Store Insights → Improve
```

### **Competence Growth**

```
Start: 50% competence (junior dev level)
After 10 tasks: 70% competence (mid-level)
After 50 tasks: 85% competence (senior level)
After 100 tasks: 95% competence (expert level)
```

## ⚙️ Configuration

### **Autonomy Level**

Edit `src/autonomous-agent.ts`:

```typescript
// How often AIRI checks for tasks (milliseconds)
setInterval(() => {
  this.autonomousCycle();
}, 10000); // 10 seconds

// Lower = more proactive
// Higher = more conservative
```

### **Task Priorities**

```typescript
// Priority thresholds
if (issue.priority > 70) {
  // Act immediately (critical bugs)
} else if (issue.priority > 50) {
  // Queue for later (improvements)
} else {
  // Monitor only (nice-to-have)
}
```

### **Task Types**

AIRI can autonomously:
- ✅ **Debug** - Fix errors
- ✅ **Research** - Search web for solutions
- ✅ **Implement** - Write code for TODOs
- ✅ **Refactor** - Improve code quality
- ✅ **Test** - Write and run tests
- ✅ **Document** - Write documentation
