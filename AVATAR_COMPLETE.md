## 🎭 AVATAR FEATURES

### 1. Emotional Expressions
```typescript
// Automatic during conversation
airi.chat("I'm excited about this project!");
// → Avatar shows excited expression

// Manual control
airi.avatar.setEmotion('happy');
airi.avatar.setEmotion('thinking');
```

### 2. Lip-Sync with Voice
```typescript
// Automatic when AIRI speaks
airi.chat("Hello!");
// → Mouth moves with voice audio
// → Stops when done speaking
```

### 3. Listening State
```typescript
// When you talk
airi.avatar.setListening(true);
// → Leans head slightly
// → Shows focused expression
```

### 4. Natural Blinking

```typescript
// Natural timing
```

### 5. Energy Animation


## 🔧 TECHNICAL SETUP

### VRM Model

```
Location: /public/models/airi.vrm

Format: VRM 1.0 (recommended)
Required:
- Humanoid rig
- Blend shapes (expressions)
- Look-at controller
```

### Dependencies

```json
{
  "three": "^0.160.0",
  "@pixiv/three-vrm": "^2.0.0"
}
```

### Installation

```bash
npm install three @pixiv/three-vrm
```
