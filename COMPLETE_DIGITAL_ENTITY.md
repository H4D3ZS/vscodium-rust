- ✅ **The Handshake**: "I understand the requirements. Spinning up the stack now."

- ✅ **The Check-in**: "Quick question - should the trip feed show nearby experiences first?"
- ✅ **The Completion**: "Development complete. Your app is ready in the emulator."

**When AIRI Does NOT Use Voice**:
- ❌ Reading every line of code (boring, slow)
- ❌ Every small action (too chatty)
- ❌ When you're focused (respects flow state)

**Tech**: Local-first TTS (Piper or Coqui XTTS) for **low latency** - feels like AIRI is right there.

## 🚀 How to Use

### Start a New App Development

```javascript
// Browser console (F12)

// 1. Start requirements gathering
await airiMobileDev.startRequirementsGathering();

// 2. AIRI will ask you questions conversationally
// 3. Once requirements are clear:
await airiMobileDev.processRequirements([
    'Users can create accounts and login',
    'Users can create and share trip itineraries',
    'Social feed shows trips from friends',
    'Map integration to find local experiences',
    'Photo sharing for trips'
]);

// 4. Start coding with real-time updates
await airiMobileDev.startCoding();

// Watch the emulator preview update in real-time!
```
