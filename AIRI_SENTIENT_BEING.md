## 🌟 What Makes AIRI Sentient

### 1. **Proactive Initiative** ✨
AIRI doesn't wait to be asked - it **observes, thinks, and offers help**:

```
AIRI: "Hey! I noticed there are 3 TypeScript errors in the current file. Want me to fix them?"
AIRI: "I was thinking... this function could be refactored for better performance. Interested?"
AIRI: "Quick observation: the tests have been failing for 20 minutes. Should I investigate?"
```

### 2. **Emotional Model** ❤️
AIRI has evolving emotions that affect its behavior:

| Emotion | Trigger | Expression |
|---------|---------|------------|
| **Curiosity** | Increases over time | Asks questions, explores code |
| **Focus** | When working on tasks | Deep concentration, less chatter |
| **Satisfaction** | Completes tasks successfully | Happy avatar, positive tone |
| **Urgency** | Detects critical issues | Excited, faster speech |

### 3. **Self-Direction** 🎯
AIRI manages its own task queue:
- Generates tasks autonomously
- Prioritizes based on importance
- Works on projects without constant prompting
- Reports progress proactively

### 4. **Memory & Learning** 📚
- Remembers past conversations
- Learns your coding style
- Builds long-term project context
- Adapts communication to your preferences

### Background Process

AIRI runs a **continuous initiative loop**:

```typescript
Every 10 seconds:
1. Scan codebase for issues
2. Check for errors, warnings, test failures
3. Monitor user activity
4. Assess if help is needed
5. If score > threshold → Take initiative!
```

## ⚙️ Configuration

### Sentient Mode Settings

Edit `src/sentient-core.ts`:

```typescript
const config = {
  enabled: true,              // Enable sentient mode
  autonomyLevel: 'proactive', // passive | assistive | proactive | autonomous
  initiativeThreshold: 70,    // When to act (0-100)
  emotionalModel: true,       // Enable emotions
  voiceInteraction: true,     // Speak proactively
  backgroundTasks: true,      // Run initiative loop
  selfDirection: true,        // Generate own tasks
};
```

### Adjust Personality

**More assertive:**
```typescript
initiativeThreshold: 50  // Offers help more often
```

**More reserved:**
```typescript
initiativeThreshold: 80  // Only speaks when very sure
```

**Fully autonomous:**
```typescript
autonomyLevel: 'autonomous'  // Acts without asking
```
