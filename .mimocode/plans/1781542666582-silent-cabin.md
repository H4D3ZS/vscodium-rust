# Fix: Codicon Font + ChatToolbar Infinite Loop

## Issue 1: Corrupted codicon.ttf (font decode error)

**Root cause:** `src/codicon/codicon.ttf` is 14 bytes containing ASCII `404: Not Found` — a failed download saved as a file.

**Fix:** Replace with the valid copy at `src/assets/codicon/codicon.ttf` (123,192 bytes, proper OpenType header).

```
cp src/assets/codicon/codicon.ttf src/codicon/codicon.ttf
cp src/assets/codicon/codicon.css src/codicon/codicon.css
```

## Issue 2: ChatToolbar infinite loop (Maximum update depth exceeded)

**Root cause:** `src/components/chat/ChatToolbar.tsx` lines 61-71 — a `.map()` inside a Zustand selector produces new array/object references every render. `useSyncExternalStore` sees them as changed, triggers re-render, infinite loop.

**Fix:** Select raw `state.availableModels`, then `useMemo` the derived mapping:

```tsx
// Before (broken):
const modelList = useStore(state => {
    const models = state.availableModels || [];
    return models.map((m: any) => ({ ... }));
}) || [];

// After (fixed):
const availableModels = useStore(state => state.availableModels);
const modelList = useMemo(() => {
    const models = availableModels || [];
    return models.map((m: any) => ({
        id: typeof m === 'string' ? m : m.id || m.name,
        name: typeof m === 'string' ? m.split('/').pop() || m : m.name || m.id,
        provider: typeof m === 'string' ? (m.includes('|') ? m.split('|')[0] : 'Ollama') : m.provider || 'Ollama',
        contextWindow: m.contextWindow,
        capabilities: m.capabilities,
        isLocal: !m.provider || m.provider === 'Ollama' || m.provider === 'ollama',
    }));
}, [availableModels]);
```
